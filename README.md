## 📌 Project Overview

**Note Sharing Pro** is a web-based platform designed to facilitate the sharing of educational materials such as notes, question papers, hand-written content, and PDFs among students, faculty, and colleges. It provides a secure, user-friendly, and centralized system that ensures quality, accessibility, and reward-based engagement via a virtual coin system.

---

## 💡 Features

* 🎓 **User Roles**: Admin, College, Faculty, Student
* 📁 **Document Upload & Verification**: Upload by users, verified by colleges
* 🪙 **Wallet System**: Earn and use virtual coins to access content
* 💬 **Global Doubt Section**: Ask and answer academic questions
* 📊 **Report Generation**: Excel/PDF-based reports and dashboards
* 🔐 **Secure Login & Registration**: Role-specific secure authentication

## 📌 Limitations of Previous Systems

* No incentive for content sharing
